# Views（绘制与界面）

全部形象用 SwiftUI Canvas 纯代码绘制，共通模式见[绘制约定](drawing-conventions.md)。

* [NiulaiView](niulai-view.md) - 主角牛来：电影直立版形象 + 全状态编排动画。
* [PetContainerView](pet-container-view.md) - 拖拽 / 点击手势装配与布局。
* [SpeechBubbleView](speech-bubble-view.md) - 对话气泡（牛来 / 豹拉共用）。
* [MenuBarContentView](menu-bar-content-view.md) - 菜单栏控制项。
* [绘制约定](drawing-conventions.md) - TimelineView + Canvas + EyeBlink 的共通模式与各角色视图索引。
